# Font assets

These WOFF2 files are Latin subsets from Google Fonts, served locally so the
chat UI works without an external font request.

| File | Family | Source |
|---|---|---|
| `fraunces-latin.woff2` | Fraunces | https://fonts.google.com/specimen/Fraunces |
| `newsreader-latin.woff2` | Newsreader | https://fonts.google.com/specimen/Newsreader |
| `plex-mono-400.woff2` | IBM Plex Mono 400 | https://fonts.google.com/specimen/IBM+Plex+Mono |
| `plex-mono-500.woff2` | IBM Plex Mono 500 | https://fonts.google.com/specimen/IBM+Plex+Mono |

All four families are distributed under the SIL Open Font License 1.1. The
Chinese text falls back to the operating system's serif face.
